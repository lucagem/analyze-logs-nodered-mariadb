# AI Insights

This is an opt-in feature. When enabled, the analyzer appends an `## AI
Insights` section to the Markdown report, generated by an Anthropic Claude
model.

## What is sent

The client builds a *digest* of the analysis and sends only that. **Raw log
lines are never transmitted.** The digest contains:

- Effective time range.
- Severity totals (CRITICAL / ERROR / WARN counts).
- Top 15 categories, each annotated with first/last timestamp, event count,
  and **two short sample excerpts** drawn from the matching events. These
  excerpts come from the rule-matched line and are clipped to 200 chars.
- Up to 20 detected restart events.
- Top 10 slowest queries (timestamp, query time, rows sent / examined,
  SQL clipped to 300 chars).

You can inspect the exact digest by reading
[`AnthropicClient._buildDigest`](../lib/services/anthropic_client.dart).

## Prompt structure

- **System prompt** sets the persona ("senior SRE") and forces a three-section
  reply: Executive summary, Likely root causes (with one-line evidence),
  Recommended next steps. The prompt explicitly forbids inventing events
  not present in the digest.
- **User message** is the digest itself, as a Markdown blob.
- `max_tokens` is `1500` — enough for a tight summary, not enough to write
  prose for hours.

## Configuring

Open **Settings** in the app:

| Setting               | Notes                                                                  |
|-----------------------|------------------------------------------------------------------------|
| `Anthropic API key`   | Stored in `<applicationSupportDir>/settings.json` (plain text).         |
| `Model`               | `claude-sonnet-4-6` (default), `claude-opus-4-7`, `claude-haiku-4-5-20251001`. |
| `Include AI Insights` | Master switch. The section is only added when this is on AND a key is configured. |

If the toggle is on but no key is configured, the report still gets an
`## AI Insights` section explaining that the call was skipped.

## Failure modes

- **Network or API error** — the request error is shown verbatim in the
  `## AI Insights` block (rendered in italics inside a blockquote). The
  rest of the report is unaffected.
- **Rate-limiting** — Claude returns HTTP 429; the same error path applies.
- **Empty content** — should not happen, but is treated as a generic
  failure and reported.

## Replacing or disabling

- To **disable globally**, remove the toggle from
  [`SettingsScreen`](../lib/ui/settings_screen.dart) or hard-code
  `getIncludeAi()` to `false` in
  [`SettingsService`](../lib/services/settings_service.dart).
- To **swap the provider** (e.g. local Ollama), replace
  [`AnthropicClient`](../lib/services/anthropic_client.dart) with another
  implementation that exposes `Future<String> generateInsights(AnalysisResult)`.
  The home screen calls only that method.
- To **enrich the digest**, edit `_buildDigest`. Keep the size bounded —
  Claude tokens add up.

## Cost considerations

Each call sends roughly 3–8 KB of input and gets back ~1.5K tokens of
output. With Sonnet you can expect a few cents per call. If you intend to
run analyses in tight loops (CI, batch), prefer Haiku and lower
`max_tokens`.

## Privacy

The digest is aggregated, but a careful prompt-injection from a malicious
log line could survive into the sample excerpts. If your logs may contain
attacker-controlled strings, treat the AI section as untrusted advisory
output and don't auto-act on it.
